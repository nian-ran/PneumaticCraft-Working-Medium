# PneumaticCraft: Working Medium（气动工艺：工质）

[PneumaticCraft: Repressurized](https://www.curseforge.com/minecraft/mc-mods/pneumaticcraft-repressurized) 的化工厂附属模组。塔、釜、压缩机柱、廊道和洁净室都靠压力、流量、温度和**工质**运转。每升一个等级，工质就会换一种：空气、油品、氮气、氩气，最后是超临界二氧化碳。

A PneumaticCraft chemical-plant addon. Towers, kettles, columns, galleries and rooms run on pressure, flow, temperature and a working medium. Each grade changes that medium, and the last grade holds supercritical carbon dioxide inside its window.

## 环境要求

| 依赖 | 版本 |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.264 或更高 |
| PneumaticCraft: Repressurized | 8.2.0 或更高（开发用 8.2.24） |
| JEI | 19 或更高，可选，用于查看结构和配方窗口 |

安装：从 [Releases](https://github.com/nian-ran/PneumaticCraft-Working-Medium/releases) 下载 `workingmedium-<版本>.jar`，放进实例的 `mods` 文件夹。

## 玩法概要

- **六个等级。** G0 是 5 bar，G1 是 10，G2 是 20，G3 是 50（要工业管），G4 是 120（要深冷管）。G5 不追求更高压力，而是守住临界釜的 70–80 bar 和 25–40 °C。弱管接到强干管上会炸，壳体等级取最弱的一块。
- **多方块机器。** 冲击破碎室、旋风分离器、洗选塔、热分釜、蒸馏塔、裂化炉、聚合釜、浸出线、压缩机柱、膨胀机、换热廊、深冷塔、洁净室、临界釜、标定台等。控制器放置时正面朝外，结构沿这个方向生长。塔类和廊道类结构可以加高、加长来提高产出。
- **管网附件。** 减压阀降一档，差额变成热；增压器用四份低压气换一份高压气；泄压阀按设定放空；表头并进管网读数。调节站的设定现在也包括 80 bar 和 120 bar，方便给流体循环回路或 G4 管线供气。压缩机列、膨胀机列和调节站的背面只用来取气或送气，不和管网直接连通，所以能真正维持和气源不同的压力。
- **配方窗口。** 每个配方都有压力和温度窗口。离开窗口时，这一炉会报废或者机器停机。出口满了机器就停，不会自动丢弃任何东西。
- **润滑与密封。** 从 G1 起，热机器要消耗润滑液，密封槽里要放密封，否则会漏气。G0 的冲击破碎室不磨损密封，也不会因为没有密封而漏气停机。等级越高的密封越耐用（G2 1000 刻，每高一级多 500 刻）。润滑液接进任意流体口都会进润滑罐。
- **自动化。** 物品输入口会把密封、催化剂、电极、无人机程序片、叶片泵、滑轨、喷嘴、气缸、膜片和夹爪送进专用槽。输入格里的稳态认证会自动用掉，但只在这台机器真正用得到认证时才会消耗。给已成形的控制器接上红石信号，机器会暂停；减压阀、增压器和泄压阀同样会被红石暂停。潜行右键不会转动已成形的控制器，以免拆掉结构、中断这一炉；壳体被拆掉时，本批进度和配方会保留，修好后可以做完。接在控制器上的漏斗只会从输出格取走物品、往输入格放入物品。配方机器控制器可以接比较器读本批进度，暂停时仍会给出进度，不会被当成已经做完。储气库、压缩机列和调节站读壳体压力；表头、表头口、泄压阀和减压阀/增压器也能输出比较器信号。物品输入/输出口、流体口、气体口和排放口会按充满程度给出比较器信号：气体口只统计气体，流体口只统计液体，并且会取进出口里更满的一侧。热口可以接热管，也会按壳体温度给出比较器信号。文丘里探针可以对减压阀、增压器、泄压阀和表头读数，对已绑定的接口使用会记下那台控制器。一批的全部产物都放得下才会开工，拆掉控制器会掉出里面的物品和整桶流体。气体口只接受、也只抽出气体，流体口只接受、也只抽出液体；管道查看罐内流体时，这两种口现在也会让它看见输出罐。多出来的润滑液可以从流体口、排放口或控制器抽回去，气体口不会抽走润滑液。换热廊会在两端之间传送热量。会产出酸、氯气、碱液或烟气的配方，必须装着排放口才会开工。
- **认证与升级。** 标定台可以反复写出稳态认证；对会耗气或输送空气/流体的已成形机器使用，或把认证放进输入格，耗气和密封磨损各减少 25%。已认证的调节站空气损耗更少，已认证的流体循环回路流量更大。已认证的压缩机列或膨胀机列保持出口气量、入口少耗 25% 空气；已认证的充气站或无人机巢每次充气也少用空气，充气速度不会变慢。物品廊、换热廊、火炬和标定台不会消耗认证。流体循环回路里的叶片泵、物品廊里的滑轨、火炬里的喷嘴、压缩机列或膨胀机列里的气缸、调节站里的膜片、充气站或无人机巢里的夹爪，都会按等级提高效率。程序片放进无人机巢后，还会给周围掉在地上的气动物品充气。充气站或无人机巢给等级钻充气时按每刻额度进行，气不够会显示流量不足；壳体里剩下的气，只要够付这一步，也能充进去。压缩机列和膨胀机列运行时要消耗润滑并磨损密封，但在气不够、这一刻做不了功时不会先扣润滑；输入罐里如果有配方并不消耗的氮气、氩气或惰性气，密封磨损会减半。裂化炉结焦或深冷塔冻结之后，会一直停着，直到潜行使用清除；红石暂停不会再盖住这两种状态，所以即使接了红石也能清除。
- **副产物去处。** 酸雾可以用碱液中和成盐水，含尘蒸汽分成水和石粉，副金属溶液电积出铜和金并回收盐酸，氢气和氯气能重新合成盐酸，水也能在电解槽里分解成氢气和氧气，炉渣和滤饼能回收铁粒，氢气、原油、煤油、汽油、液化气、单体、增塑剂和重蜡，以及配了氧气的原油、柴油、煤油、汽油或液化气，都能在联合循环岛里燃烧并给壳体充气。火炬可以烧掉氢气、烟气、酸雾、氯气和含尘蒸汽并放出热量，但不会烧掉氮气、氩气、氧气或惰性气。四张废片能烧结回层压基板，金属灰在惰性气体下烧结能得到两份催化剂。沥青是一条更快的路，也可以用四份石粉加一份重蜡合成。氯气、酸雾、盐酸、碱液、酸料和烟气会伤害走进去的生物。含尘蒸汽会烫伤。氢气在已着火或旁边有火焰（包括火把、灯笼、南瓜灯、点燃的蜡烛、正在烧的熔炉、点燃的营火和熔岩锅）时会点燃，漏出来的氢气碰到火还会把整摊烧掉。氧气仍会冻伤，但遇到已经着火的生物会让火更旺，氧气不会灭火。液体二氧化碳、氮气、氩气和氧气会冻结并减缓走进去的生物；液体二氧化碳、氮气和氩气还会熄灭身上的火，并扑灭旁边的火或营火。
- **产业链。** 冲击破碎室可以把圆石、石头、砂砾、深板岩、深板岩圆石、黑石、下界岩、安山岩、闪长岩、花岗岩、凝灰岩、玄武岩、方解石或末地石打成石粉，下界岩还会掉出金粒；用精准采集拿到的铁矿、铜矿和金矿（含深板岩和下界金矿）能打出两份破碎矿；用精准采集拿到的煤矿、红石矿、青金石矿、钻石矿、绿宝石矿和下界石英矿也能打出更多产物，荧石、紫水晶块和石英块能打回四份，砂岩和红砂岩能打成四份沙子，骨块能打成九份骨粉。四份石粉能合成回圆石，也可以在润滑混合釜里加水做成粘土。矿石洗选和浸出可以做到双倍或三倍矿，铜和金也能走浸出拿到三倍锭；洗选塔还能把破碎的古残骸洗成下界合金碎片，也能用水把砂砾洗成燧石和石粉，把沙子或红沙洗成粘土球，或把任意颜色的混凝土粉末浇成混凝土。原油经热压、蒸馏、裂化和聚合得到燃料、蜡、单体和工程塑料；残渣窑还能把两份沙子或两份红沙烧成三块玻璃，把两份粘土球烧成三块砖，把两份下界岩烧成三块下界砖，把两块圆石烧成三块石头，把湿海绵烤干，把两块粘土块烧成三块陶瓦。淬火井按流体决定合金：液化气把压缩钢淬成瓷封合金，液体二氧化碳把瓷封合金淬成深冷合金；同一口井也能用液体二氧化碳把水冻成浮冰，再把浮冰冻成蓝冰，或把熔岩淬成两块黑曜石，用水淬熔岩则只得到一块。深冷塔分出氮气、氩气、氧气和液体二氧化碳，供洁净室和临界釜使用。层压出来的微流控芯片要在洁净室洗净，临界釜必须装着已洁净的芯片才能做临界芯。电解槽必须装着电极才会开工，除了电解盐水，也可以把水分解成氢气和氧气。润滑混合釜用海带或干海带加水能做出盐水。洗涤塔还能用碱液把盐酸或酸料中和成盐水。多出来的重蜡可以送进联合循环岛烧掉。
- **无人机。** 编程片 `workingmedium_read_gauge` 读取表头，`workingmedium_hold_window` 在机器处于窗口内时停留。
- **游戏内资料。** 合成「工艺规程」查看全部说明。安装 JEI 后，可以看到每台多方块的最小结构示意和完整的配方窗口。

## 从源码构建

需要 Java 21。

```bash
./gradlew test
./gradlew build
```

Windows 上用 `gradlew.bat`。构建出的 jar 在 `build/libs/`。

贴图和模型由 `python3 tools/gen-assets.py` 生成，音效由 `python3 tools/gen-sounds.py` 生成。贴图、模型和音效都是本模组原创，没有复制气动工艺官方的资源。
